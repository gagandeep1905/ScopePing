# Frequently asked questions

## Is ScopePing a hosted subscription?
No. This purchase is a downloadable source-code and template kit. You get files to preview, customize and deploy your own copy. It does not include hosted access, a custom domain, hosting, API credits, or ongoing AI service.

## Do I need to know how to code?
You can preview the app by opening `index.html`, but deploying a personalized copy and configuring the optional API requires basic GitHub/Vercel setup. This is a developer-oriented source kit, not a no-code hosted service.

## Is Gemini required?
No. ScopePing has a local keyword-based check and quote workflow. Live AI-assisted comparison is optional and requires your own Google AI Studio API key.

## Is the AI API free?
Google may provide a free tier for eligible models, but availability, rate limits and terms vary by account, region and model. This product includes no AI credits and cannot guarantee free access. Verify the provider's current terms and pricing before use.

## Can I use it for client projects?
The included license permits one purchaser to use and adapt the product in their own freelance/business workflow, subject to the license. It does not permit reselling or redistributing the source files as a template, source-code pack or competing product.

## Does it store information in the cloud?
No. The browser app uses localStorage for workspace settings and saved requests. Data stays in the same browser profile on that device, unless you export it or clear browser data. The optional AI request sends the scope and request text to Google when analysis is enabled.

## Is the change-order PDF legally binding?
No. It is an editable working document and not legal advice. Review the wording, original contract, payment terms, applicable law and sign-off process before sending it.

## Can I remove the AI parts?
Yes. The source files can be customized. The local scope check, calculator, message generator and PDF flow can be used without a live AI key.

## The PDF button does nothing. What should I do?
Check that your browser has internet access and can load the jsPDF CDN script. Refresh the page and try again. If you use strict privacy extensions or a network filter, allow the CDN used by the HTML page.

## The app displays LOCAL CHECK.
Read the notification. It may mean the API key is missing, the provider rejected the request, the model is unavailable, or quota/rate limits were reached. Confirm your Vercel environment variable and current provider status.

## What is not included?
Custom setup, hosting, support for third-party services, API usage, legal review, cloud sync, user accounts, a database, payment processing, custom integrations and guaranteed service availability.
