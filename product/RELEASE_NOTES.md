# ScopePing product kit — release notes

## Included in the current download
- Scope baseline and new change-request workflow.
- Optional server-side Gemini scope comparison (buyer supplies their own key).
- Local keyword-check fallback.
- Extra-hours, timeline and fee calculator.
- Client-ready reply builder (English/Hinglish).
- Browser-generated change-order PDF.
- Request log and JSON export.
- Buyer setup, privacy, FAQ, license and troubleshooting documentation.

## Limitations
- No hosted account or subscription is included.
- No third-party API key or credits are included.
- Browser-based data storage does not sync across devices.
- AI analysis is optional; local fallback is not a language model.
- No legal advice or guaranteed estimate accuracy.
