## Product description (paste into Gumroad)

Stop guessing what to charge when a client asks for “one small change.”

**ScopePing is a downloadable source-code and template kit for freelancers who want clearer scope conversations, more consistent quotes, and professional change-order documents.**

### What you can do
- Record the original project scope, project value, revision allowance and hourly rate.
- Compare a new request with the agreed scope using the local rules-based checker or your own optional Gemini API key.
- Estimate extra hours, timeline extension and an add-on fee.
- Draft client replies in English or Hinglish.
- Generate a branded change-order PDF with scope notes, proposed fee, timeline, approval terms and signature/date lines.
- Track requests in your browser and export a JSON backup.
- Customize the HTML, CSS and JavaScript to fit your workflow.

### What you'll receive
- ScopePing source files (HTML, CSS, JavaScript and Vercel API route)
- Setup and deployment guide
- Buyer quick-start and troubleshooting guide
- FAQ and single-purchaser license
- Blank change-order template and sample PDF documents
- Gumroad listing assets / product documentation

### Who it is for
Freelance web developers, designers, independent consultants and small studios that want a practical way to document proposed scope changes before starting extra work.

### Important requirements
- This is a **downloadable source-code/template kit**, not a hosted SaaS subscription. No hosted account, custom domain, hosting, API key or AI credits are included.
- Preview the UI locally. To enable live AI comparison, deploy your own copy and configure your own Google Gemini API key.
- The optional AI provider is a third party; quotas, prices, model availability and its terms can change.
- The local fallback works without an API key but uses simple keyword rules and is not equivalent to an AI model.
- The browser-based PDF generator loads jsPDF from a CDN and requires internet access when creating the PDF.

### Privacy note
When Gemini analysis is enabled, the project scope and client request are sent to Google. Google’s unpaid API terms may permit submitted content to be used to improve Google products. Do not submit confidential contracts or personal/sensitive client information through a free-tier API key. Review current provider terms and obtain client permission where needed.

### Not legal advice
ScopePing's comparison, estimates, sample change-order language and reply drafts are informational starting points only. Verify the actual agreement, deliverables, fee, deadline, tax and payment terms before sending anything to a client.

**Download the files, test with sample data, and adapt the workflow to your own practice.**
